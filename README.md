# Sequential Raccoon OS

A custom Linux distribution built progressively from the Linux kernel upward.

## Goals

- Custom Linux kernel configuration and development
- Controlled userspace
- Custom init/service layer
- Custom package format and package manager
- Custom package repository
- Reproducible ISO builds
- Custom installer
- QEMU-based testing
- Progressive replacement of underlying Arch components

## Development Philosophy

Start with proven Linux/Arch components, understand them,
then replace individual components with our own implementations.
